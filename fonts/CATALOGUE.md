# Font catalogue

Per family: themes, licence, axes or weights, what it is good for, what to avoid, and pairings. The notes are this repo's own craft guidance, written for it. Family names link to the source folder in [google/fonts](https://github.com/google/fonts); licence links go to the file in this repo. How to pick: [README.md](README.md). Generated by `fonts/build.py` from `catalogue.json`; edit the JSON, not the tables.

Axis tags: `wght` weight, `wdth` width, `opsz` optical size.
