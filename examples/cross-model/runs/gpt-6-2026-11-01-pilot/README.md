# Creative Director — GPT tester pilot

This ZIP contains a practical pilot evaluation with paired baseline-style and skill-style critique outputs, a revised bakery HTML artifact, and an honest scorecard.

**Important:** the paired outputs were authored in one conversation after the repository rubric was inspected. They are not six independent fresh-chat runs. Scores are indicative, contaminated by the visible rubric, and must not be reported as a clean benchmark.

Contents:
- `outputs/task-a/`: two critiques and revised HTML
- `outputs/task-b/`: baseline-style and skill-style illustration critiques
- `outputs/task-c/`: baseline-style and skill-style technical drawing critiques
- `results/scorecard.md`: indicative scores, caveats, and a protocol for clean replication

Original inputs and rubric: https://github.com/SnazzyGaz/creative-director/tree/main/examples/cross-model
