# Tools

Small scripts that back the **Auto: yes/partly** notes in the modules. Python 3 with Pillow and numpy; `autocheck.py` page mode needs playwright with chromium (`pip install playwright && playwright install chromium`); `vp.py detect`, `ellipse.py` and `grid.py` also need OpenCV, and `intersect.py` needs trimesh, rtree and manifold3d (`pip install -r tools/requirements.txt`). `shot.sh` needs google-chrome.

| Script | What it does | Rules |
|---|---|---|
| `autocheck.py IMG\|PAGE.html\|URL [--out DIR] [--json F] [--text-box x0,y0,x1,y1[:large]] [--print WxHmm] [--intended Y0-Y1]` | One command, no judgement: runs every measurable check and prints PASS / FAIL / FLAG / SKIP with rule ID, measured value and the rule's own threshold, plus JSON. Pages (playwright + chromium): contrast against the worst ground pixels behind each text run (text-hidden screenshot), text size, number of type sizes and near-duplicates, line length, line spacing, spacing scale, near-miss gaps and uneven gutters, text crowding the frame, dead space, balance, touch targets and text size at 390 px, sideways scroll and clipped text at 200% zoom. Images: dead space, balance, edges and safe margin, print resolution, and contrast only inside given text boxes; text checks are SKIP with the reason. Balance is only ever FLAG. Exit 1 on any FAIL | critique loop step 3; UI-5, UI-6, UI-10, TYPE-2 to TYPE-5, CORE-4, COMP-19, COMP-24, LAY-5, LAY-9, LAY-10, LAY-15 |
| `look.py IMG SHEET.png` | One contact sheet with the five look tests (blur, thumbnail, flip, greyscale, edges), plus L* value stats and a "what leads" grid | critique loop step 2, CORE-2, CORE-3 |
| `contrast.py < pairs.txt` | WCAG contrast ratios, with alpha compositing | UI-6 |
| `shot.sh FILE.html PREFIX` | Headless screenshots at 390 px, 1280 px and 200% zoom | UI-10, critique loop step 1 |
| `beforeafter.py A B OUT.png` | Labelled side-by-side of two rounds | critique loop step 4 |
| `vp.py fit SEGS.csv` / `vp.py detect IMG OUT.png` | Least-squares vanishing points per edge family, horizon tilt, VP height mismatch, tilt of verticals. `detect` finds long straight segments to sort into groups | TD-PER-1, TD-PER-3 |
| `ellipse.py IMG ROI [--axis ...]` | Fits an ellipse in a box (RANSAC over the edge pixels, so side lines and hatching don't pull it). Reports degree, tilt of the axes and the minor axis against the form's axis, fit residual, and an end check that flags pointed ("lemon") or flattened ends | TD-ELL-1, -2, -3 |
| `intersect.py MODEL [--up y\|z] [--unit m] [--tol 1] [--near MM]` | For a GLB/glTF/OBJ/STL/PLY: parts that cut into each other (shared volume, depth, "passes right through"), parts floating off the ground or their support, and near-miss gaps between parts. Exit 1 if anything is found | 3D-1, 3D-2 |
| `lookbook_find.py --use ... --mood ... [--avoid ...] [--skip IDs] [--colour HEX,...] [--like ID]` | Shortlists lookbook looks from `modules/lookbook/looks.json` by use, mood and energy (word-start matching); drops avoid-for matches and recently used IDs; `--colour` ranks by nearest dominant colours, `--like` lists a look's visual neighbours; prints sheet and hint for each. Scored by `modules/lookbook/tests/score_find.py` | lookbook module |
| `lookbook_sync.py BREEDER [--dry-run \| --enrich-only]` | Folds a new lookbook batch in: copies only manifest files, filters to shareable live looks, keeps retired IDs, derives `nearest_looks`, `colours` and `getty_aat`, runs the name check (`modules/lookbook/UPDATING.md`) | maintenance, not a design check |
| `fetch_assets.py [--examples\|--lookbook\|--all]` | Downloads the files kept out of git from the assets-v1 release, checks them against `SHA256SUMS.txt` and unpacks them in place: font files by default, full-size example images and lookbook sheets on request | packaging, not a design check |
| `check_budgets.py [--loads]` | Token budgets for the rule files: the always-on set (6,500), lite (2,500), each module README (6,000), every other rule file (4,500). tiktoken `cl100k_base` when installed, else characters / 4. `--loads` prints the typical loads from `core/which-modules.md`. Exit 1 if anything is over; run by the GitHub Action | packaging, not a design check |
| `package_skill.py [--check] [OUT.zip]` | Builds the portable skill folder `skills/creative-director/` (`SKILL.md` generated from `AGENTS.md`, plus `core/`, `modules/`, `lite/`, the design tools, the font catalogue, `SOURCES.md` and `LICENSE`; no images, tests or maintainer scripts), checks the name and description limits, and zips it to `dist/creative-director-skill.zip`. `--check` fails if the committed folder is out of date | packaging, not a design check |
| `build_bundle.py [--check]` | Builds the single-file prompt bundles for chat LLMs: `dist/creative-director-prompt.md` (`AGENTS.md`, principles, loop, template, commands) and `dist/creative-director-prompt-full.md` (all of `core/` and every module). Same sources give identical files | packaging, not a design check |
| `anatomy_crops.py IMG OUT "label:x0,y0,x1,y1" ... [--zoom 3]` | Zoomed crops of each hand, limb join, face or animal head, a labelled sheet with an overview, and a blank pass/fail record (A1-A11). Doesn't judge anatomy: it forces the close look and the written line per region | CHAR-9, CHAR-10 |
| `grid.py SHOT.png [--out overlay.png] [--scale 4]` | Layout grid from a screenshot: left-edge alignment lines and boxes that miss one by 2-6 px, rows of cards with uneven tops, steps, gaps or padding, and whether gaps between boxes sit on a 4 or 8 px scale | CORE-4, CORE-5, UI-4 |
| `balance.py IMG [--bg R,G,B] [--sheet OUT.png]` | Visual-weight balance: weights each pixel by how far it stands out from the background (lightness plus some chroma), then reports the weighted centroid's offset from the frame centre (DCM), and the right/left and bottom/top weight ratios, with a sheet showing the centroid. Never fails: off-centre can be intended, and a lever-balanced asymmetric layout also reads near equilibrium. Never centre a piece just to lower the number (COMP-19). Pixels can't see faces, words or gaze, so finish by eye | COMP-2, COMP-19, COMP-2, CORE-11 |
| `whitespace.py IMG [--intended Y0-Y1,...] [--axis left\|right] [--sheet OUT.png]` | Whitespace distribution on a squinted copy: empty horizontal bands compared with the other interior gaps (FAIL above 1.5×), and the largest empty 2-D region (dead zone) compared with the layout's own gaps and margins. Skips gaps marked intended, the symmetric flanks of a centred group, and the open side of a flush-left or flush-right layout. Exit 1 on FAIL; a PASS still means "look at the sheet by eye" | LAY-10 |

**Tests:** `python3 tools/tests/autocheck_cases.py` (6/6: four image fixtures, two page fixtures; page cases skip without playwright), `ellipse_cases.py`, `intersect_cases.py` (needs trimesh, rtree and manifold3d), `grid_cases.py`, `whitespace_cases.py`, `balance_cases.py`, and `modules/lookbook/tests/score_find.py` (lookbook search: recall@8 0.979 on 32 briefs, 0 violations). Each builds synthetic good and bad cases and most also run the tool on matching files in `examples/` (those files stay in git at full size). Current results (v0.9.1): autocheck 6/6; ellipse 32/32 synthetic + 4/4 example images; intersect 6/6 synthetic + 2/2 (the stool, broken and fixed); grid 18/18 (synthetic + example screenshots); whitespace 5/5 synthetic + 3/3 example images; balance 6/6 synthetic + a smoke run on the case-study images. The GitHub Action runs all seven on every push.

**`intersect.py` and model-qa.** [model-qa](https://github.com/SnazzyGaz/model-qa) is the companion repo: a broader Blender-based build check (symmetry, normals, scale, gaps, close-up renders). In `examples/common-failures/` it reported the stool's leg poking through the seat only as "asymmetry". `intersect.py` is a narrower, Blender-free check for exactly two faults, intersecting and floating parts, and names them directly. Use model-qa for the full build check and `intersect.py` when parts must touch without cutting into each other; they don't share code.

**Limits:**
- `vp.py` does not group edges into families: a bot or person does. Its result depends on the endpoints, so take them at zoom. Far vanishing points are unstable (see the `spread` figure).
- `ellipse.py` needs a box around one ellipse; a loose box round concentric rims can lock onto a different rim (seen on the generated can in `technical-drawing-still-life/`). Half-visible ellipses give an approximate degree. Since v0.3.0 it catches the planted lemon in `examples/technical-drawing-takeover/` (end check 0.71/0.68 against ~1.0-1.15 for a true ellipse; overlay `ell-r01-top-v03.png`), which v0.2.0 missed. The end-check thresholds were set on the same synthetic and example cases they are tested on, and on only two real (generated) drawings: treat a borderline reading (0.9-0.95, 1.2-1.3) as "look at 2x". Ellipses drawn with a wobbly hand line are untested.
- `intersect.py` treats every overlap as a fault, so it also flags intended joints (a dowel in a hole, a tenon in a mortise): read the list against the design. Non-watertight parts fall back to a vertex-depth test with no volume. Ground is the model's lowest point, so a model that is wholly floating (nothing at ground level) isn't caught; pass a scene with its floor or check the placement by eye.
- `grid.py` sees ink, not the DOM. It checks rows, gaps and padding only between "solid" boxes (with a border, background or image edge); text blocks a few px off a line are listed as "check", because letter side bearings move ink by 1-5 px. Vertical gaps between text blocks are printed but not judged. Centred layouts give it few lines to work with. On the existing `web-ui-*` screenshots it raises no false alarms, but those pages have few framed boxes, so they test silence more than detection.
- `whitespace.py` measures ink, not intent: a deliberate breathing space must be passed with `--intended`, and the thresholds (1.5× band, 1.5× dead zone, 3% area) were set on a small set of posters and signs. It cannot judge whether the space is *well used*, only whether it is evenly spread.
- `balance.py` is a pixel model of the steelyard: it weighs contrast and chroma, not meaning. A small face, a word or a pointing gaze can outweigh what it measures (COMP-3), and studies find balance only loosely linked to liking. Its reading bands (10 and 25) are self-chosen.
- `autocheck.py` reuses `contrast.py`, `whitespace.py` and `balance.py`, so their limits apply. On pages it reads pixels for contrast and space: a dark canvas, video or flat photo counts as space (so dead space is only a FLAG there), and text over a busy ground that passes at its median is a FLAG, not a FAIL. Type checks read computed styles, so text drawn in images or canvas isn't seen. Its spacing-scale and near-miss lists are flags because CORE-4 sets no pass rate. Thresholds come from the rules; where a rule's number is self-chosen the output says so.
- Confirm overlays by eye. Tested on `examples/technical-drawing-still-life/` (see `measurements.md` there).
